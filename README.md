AI Test Skills Collection

## Skills

| [test-case-designer](./test-case-designer.md) | 测试用例设计器 - 分析业务流程、拆解测试场景、区分测试层次、标注优先级 |
| [test-coverage-reviewer](./test-coverage-reviewer.md) | 测试覆盖审查员 - 对照测试计划检查覆盖情况、输出未覆盖清单、评估发版风险 |
| [qa-orchestrator](./qa-orchestrator.md) | QA 编排器 - 协调测试设计、覆盖审查与执行的工作流 |
